## 0.1.0 (2026-11-05)

### Features

* HTTP redirect server on the BEAM with lock-free rule lookups
  (`persistent_term`): exact, prefix and regular expression rules, per-host
  rules with a `*` wildcard, capture substitution (`$1`, `${n}`), query string
  preservation and 301/302/303/307/308 statuses.
* Rules persisted to a versioned JSON file with atomic writes, rotating
  backups, an append-only audit log and validated hot reload (`SIGHUP` or
  admin button).
* ReDoS protection: catastrophic regular expressions are rejected and every
  match runs with a PCRE backtracking budget.
* Administration backend (Bootstrap 6): CRUD, search and filters, enable /
  disable, URL tester, JSON import / export, local users, audit log.
* Authentication: local accounts (PBKDF2-SHA256), OpenID Connect SSO
  (authorization code + PKCE) and trusted reverse-proxy headers; server-side
  sessions, CSRF tokens, origin checks and login throttling.
* Prometheus metrics, health endpoints and a CLI (`serve`, `check-config`,
  `user`, `rules`).
* Release bundles with the Erlang runtime, Debian/Ubuntu packages, multi-arch
  container images and a Homebrew formula.
